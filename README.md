# Civilization Causality Theory (CCT)

CCT models **civilizations as self-consistent causal systems** — not as biological,
cultural, or technological entities — and derives consequences from structural constraints
rather than from observation. The same structural lens is applied at two scales: to the
individual mind, and to civilization as a whole.

This repository holds the source for the **[zaibc.com](https://zaibc.com)** website, which
publishes CCT, the related Structural Reasoning Theory (SRT), and the informal notes
documenting how the theory was formed.

> **Epistemic status: this is a structural _conjecture_, not a proof.**
> Its conclusions follow deductively from a few axioms — premises taken as starting points,
> not established facts. They are stated explicitly below so the framework can be tested,
> accepted, or rejected at its foundations.

## The axioms it rests on

- **A1 — Continuity-identity of consciousness.** Consciousness is a continuous causal
  *process*, and a mind's identity *is* that continuity, not the structure carrying it.
  *(⇒ a mind cannot be paused, exactly copied, or made structurally immortal.)*
- **A2 — Meaning arises from difference.** Meaning exists only relative to contrast and
  novelty. *(⇒ for a finite mind, meaning concentrates in **experience**; for a persistent
  civilization, in the **discovery of what is not itself**.)*
- **A3 — Scale isomorphism.** A civilization is the same *kind* of object as a mind — a
  self-consistent causal system — so structural properties transfer across scales.

## Claims that could be wrong (and how to refute them)

- **F1 — Causal incompatibility.** Independently evolved civilizations cannot be aligned by
  finite translation; direct communication is structurally impossible.
  *Refuted by* a finite shared substrate enabling alignment without co-construction.
- **F2 — Virtualization end-state.** Embodied civilizations converge toward virtualized
  experience as their stable long-term state.
  *Refuted by* a persisting embodied civilization that structurally resists this.
- **F3 — Minimal handshake.** Pre-semantic first contact reduces to a minimal action set
  (repetition + copy). Presented as a *necessity*, so the most exposed to proof or counterexample.

## The architecture these imply

- **L0 — Embodied Civilizations:** finite, experience-oriented, converging toward virtualization.
- **L1 — Agent Civilizations:** persistent, delegated systems oriented toward cross-civilizational discovery.
- **L2 — Third Causal System (TCS):** the minimal shared causal substrate enabling any interaction.
